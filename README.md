# 幻想三国 · 经典版 Web 亲友怀旧服 (HXSG)

1:1 复刻汉风《幻想三国-经典版》（A 版复古像素视觉与交互）的 Web 亲友怀旧服项目，专为 200 人以内的亲友怀旧服设计，单容器即可在 **2C4G** 轻量服务器上流畅运行。

## 第一阶段已实现功能

- **1:1 经典版（A 版）原版视觉**：使用官方解包无损 PNG 切图（顶栏底纹、人物/设施/移动/功能四大主按钮、红底金框、3 副将槽位、7 菱形战斗指令、战场地形拼接、头/身/腿拆件像素小人动画、闪电/火攻/法攻特效、胜利/败北横幅、深蓝选区页与深紫祥云子界面）。
- **核心玩法闭环**：
  - 账号注册 / 登录（首个注册账号自动成为服主 GM）与分区选择
  - 三职业（武士 / 文人 / 异人）男女创角与实时像素预览
  - 经典地图移动（许昌 / 许昌郊外 / 长社 / 洛阳 / 洛阳城外 / 涿郡）
  - 像素回合制战斗舞台（手动/自动战斗、快捷键 `1-7`、职业技能、战中吃药、残血招降副将、经验/银两/升级/掉落结算）
  - 设施交互：客栈免费满血满蓝、回春药铺买药、招贤馆招募副将（关平/黄月英/于吉/赵云）与 3 槽位出战切换
  - 实时 WebSocket 聊天（区 / 派 / 商 / 世）与同地图在线玩家像素头像条
  - 全服排行榜（高手榜 / 富豪榜 / 金砖榜）与亲友服 GM 面板

## 技术栈

- **前端**：Vite + React 19 + TypeScript + Tailwind CSS + 2D 像素 Canvas 战斗舞台
- **后端**：Fastify + Socket.IO + Node 内置 `node:sqlite`（WAL 模式，免原生编译）
- **资源需求**：2C4G 轻量服务器可稳带 200 玩家（内存占用 < 400MB），建议带宽 ≥ 4Mbps

## 本地启动

```bash
pnpm install
pnpm dev
```

- 前端开发地址：`http://localhost:5173`
- 后端服务地址：`http://localhost:3001`

如需从本地 `raw/unpacked/` 重新同步原版美术素材：

```bash
pnpm run assets:sync
```

## 2C4G 服务器一键部署（Docker）

```bash
# 修改环境变量中的密钥与 GM 口令后启动
HXSG_SECRET="your-random-secret" HXSG_GM_CODE="hxsg888" docker compose up -d --build
```

SQLite 数据持久化在宿主机 `./data/hxsg.db`，备份或回档只需拷贝该文件即可。
